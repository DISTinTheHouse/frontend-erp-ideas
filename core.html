Panel de Control

Configura empresas, estructura organizacional, usuarios, seguridad y catálogos base con una experiencia fluida.

Áreas

Catálogos base

Empresas

Registra cada razón social que operará dentro del sistema ERP.

La empresa quedará lista para asociar sucursales y departamentos.

Sucursales

Define las sedes físicas u operativas asociadas a cada empresa.

Las sucursales se utilizarán para segmentar operaciones y folios.

Departamentos

Organiza áreas internas para asignar responsables y presupuestos.

Los departamentos se utilizarán para análisis y flujos de aprobación.

Usuarios

Crea las cuentas de acceso que utilizarán los módulos del ERP.

El usuario quedará listo para asociar permisos y módulos.

Roles de usuario

Agrupa permisos en roles reutilizables para simplificar la asignación.

Los roles se asignan a usuarios para heredar permisos.

Permisos

Define acciones específicas que los usuarios podrán ejecutar.

Los permisos se relacionan con roles y usuarios.

Monedas

Catálogo base de monedas, utilizando únicamente el identificador.

Solo se registra el identificador para relacionarlo con otras tablas.

Impuestos

Catálogo base de impuestos, utilizando únicamente el identificador.

Solo se registra el identificador para relacionarlo con otras tablas.

Unidades de medida

Catálogo base de unidades de medida, con identificadores simples.

Solo se registra el identificador para relacionarlo con otras tablas.

Series y folios

Define las series y folios base asociados a cada sucursal.

Solo se registran los identificadores para relacionarlos con CFDI y documentos.
